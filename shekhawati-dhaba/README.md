# Shekhawati Dhaba Website

A responsive React + Vite + Tailwind CSS restaurant website with separate pages:
- Home (`/`)
- Menu (`/menu`) with search and category filters
- Our Story (`/about`)
- Locations (`/locations`)
- Contact (`/contact`)
- Book a Table (`/booking`)

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal in this folder (the folder containing `package.json`).
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL shown by Vite, usually `http://localhost:5173`.

## Before publishing
Replace sample menu entries, prices, contact details, opening hours and unconfirmed branch details with information supplied by the restaurant. The table-booking form is a front-end demo only; connect it to a backend/service before accepting real bookings.
